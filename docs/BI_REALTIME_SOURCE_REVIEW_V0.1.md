# Hanson BI 实时经营数据源评审 v0.1

## 结论

lann-site 当前没有部署到 Hanson 服务器，主要在本地运行；但本机通过只读 BI API 连接的就是 Hanson 数据服务。

当前正式归因链使用的 `report_store_month_indicator_export` 截止 2026-03。这是 CTO 王磊提供的第一稿月度数据。Hanson 工作台另有更新到 2026-07-17 的门店日结表，来源是店长每天完成结算后的记录。

重叠期对账确认：日结表的 `prod_amt` 与月度“实际营收”高度一致，可以作为选址分析的后续经营数据源；`flow_amt` 包含其他资金流，不能作为营业收入。

## 1–3 月重叠期对账

保留城市名、只清理门店名格式噪声后，共得到 230 个有效可匹配门店月：

- 差异不超过 1%：211 个，占 91.7%。
- 差异 1%–5%：18 个，占 7.8%。
- 差异超过 5%：1 个，为武汉天地店 2026-01；该月只有 17 个日结日，月度 67,140.49 元、日结 62,157.49 元，差 4,983 元（-7.42%）。
- 单店月差异绝对值中位数为 0.17%。
- 匹配样本总额：月度指标 64,242,286.25 元，日结 `prod_amt` 64,050,363.78 元，日结低 191,922.47 元（-0.30%）。
- 分月差异稳定：1 月 -0.25%，2 月 -0.30%，3 月 -0.34%。

差异 1%–5% 的 18 个门店月涉及 11 店：成都太古里旗舰店、新达汇三林店、梅赛德斯奔驰文化中心店、深圳湾万象城店、白玉兰广场店、温州滨江万象城店、长宁来福士店、花木陆悦坊店、静安大悦城店、上海汇智国际商业中心店、中兴壹号店。最大一笔是成都太古里旗舰店 2026-03，月度 482,779.33 元、日结 466,189.10 元，差 -3.44%。

另有 49 个“仅月度源”门店月，金额全部为 0，主要是支持中心、培训部、新店模型、未开/已停门店等占位记录，不构成有效营收缺失。

### `flow_amt` 误判案例

新天地店 2026-01 至 03 的月度实际营收约 49 万/月，日结 `prod_amt` 也约 48–49 万/月；但 `flow_amt` 为 127–140 万/月。日结每天只有一条，不是重复结算，差额主要来自 `flow_amt` 同时包含约 107–123 万/月的卡类金额。由此确认日结营收字段应使用 `prod_amt`。

## 建议接入方式

1. 王磊月度稿继续保留为 2026-03 及以前的历史基准和定期校准源。
2. Hanson 日结 `prod_amt` 按门店、自然月聚合，从 2026-04 起补充正式经营结果；同时提供滚动 30/90 天趋势。
3. 选址判断允许这一精度：重叠期总体差 0.30%、中位单店月差 0.17%，明显小于业务判断本身的不确定性。
4. 设置数据质量闸门：日结天数不完整、迁址/装修过渡月、金额为 0、门店身份未映射时标记观察，不直接进入租售比和“好店”判定。
5. 对 15% 租售比阈值附近的门店保留人工复核缓冲，避免 1%–3% 的个别口径差异改变边界结论。
6. 后续若部署服务器任务，每日只拉门店级聚合结果并保留源日期/字段，不拉客户或订单明细。

本次对账明细仅保存在本地 `data/staging/bi_revenue_source_reconciliation.csv`，不进入 Git。
