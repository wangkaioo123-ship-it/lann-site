# 现有门店经营归因 v0.1

## 口径调整

当前阶段不把历史选址测算与实际业绩的匹配度作为主线。

立项信息表和选址调研报告先用于理解 LANN 的选址业务结构、资料结构和经营模型字段，不先评价历史测算是否准确。第一阶段主线改为：

1. 先基于各店实际业绩、租金和经营指标做结果分层。
2. 再从结果分层反推可能的选址归因。
3. 最后定向补充这些样本对应的选址调研字段，用于进一步验证归因。

补充：目标管理周报中的“目标达成率”是集团给分公司的年度实际收入目标在阶段内的达成情况。该指标用于校准最新经营状态和分公司经营节奏，不直接作为门店选址好坏标签。

## 数据输入

## 经营结果标签

经营结果标签用于挑选归因研究样本，不等同于“好店达标”。输出新增独立的“好店经济性 Gate”：有效营收月份不少于 6 个月、平均月营收不低于 28 万、租售比不高于 15%。即使经济性达标，仍需补充新客稳定性、老客复购和业绩波动，才能形成完整好店结论。

v0.1 根据营收、月租金、租售比、新客、客单、理疗师产值和现有样本角色，给门店打标签。

后续 v0.2 需要调整权重：

- 选址一阶指标：新客数量、新客储值转化率、折扣前客单价。
- 经营承接/运营诊断指标：开卡、点钟、理疗师产值、理疗师生产率、复购频次。
- 经济性约束指标：租售比，目标好店标准为 15% 以内。
- 稳定性指标：月业绩波动、老客复购频次、成熟期后表现。

理疗师产值等承接指标不能直接作为选址优劣主因，只用于剥离“位置带来客流”与“门店承接能力”的差异。

- 正向样本-新客驱动
- 正向样本-高产值承接
- 正向样本-结构健康
- 反向样本-租金高且营收弱
- 反向样本-租金不高但营收弱
- 异常样本-高租金高营收承压
- 异常样本-新客弱但承接强
- 异常样本-新客强但承接弱
- 成长样本-新客强租售比健康
- 观察样本-经营期不足
- 压力样本-租金偏高
- 中性样本-待结合调研

关键规则：

- 有效营收月份少于 6 个月的门店只进入观察池，不定性为正向或反向样本。
- 新客分位靠前且租售比健康的门店，即使营收分位暂时偏低，也优先判断为成长/承接观察，不直接判为反向样本。

## 调研字段补充逻辑

不是全量补所有调研字段，而是按经营结果标签定向补：

- 新客强/弱：补客质和人流、常驻人口、周边小区、写字楼、商场客流评级。
- 租金压力：补租金物业月成本、面积、商场年销售额评级、商场竞争力、远景机会。
- 营收强/弱：补商场定位、商圈等级、品牌组合、点评摘要、同类竞品、竞争性、风险性。
- 产值强/弱：补客质和人流、点评、同类竞品、商场定位，用于区分选址和运营承接。

新增校准原则：

- 若门店新客强、储值转化强、折扣前客单价较好，即使短期营收未完全达标，也不应优先归因于选址差。
- 若门店营收低但租售比低，需要重点检查新客、储值转化、客单价和复购，而不是简单判断为“便宜但无效”。
- 若门店营收高但租售比高，需要判断是否是直营/合资核心 CBD、品牌影响力或战略点位带来的合理承压。

4. 再把验证后的有效字段升级为候选点位调研模板和新点位判断规则。
