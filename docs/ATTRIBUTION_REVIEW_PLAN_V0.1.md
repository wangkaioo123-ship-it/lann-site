# 选址归因复盘工作计划 v0.1

## 操作顺序

当前不全量补调研报告，也不先扩大外部数据抓取。先按经营结果挑代表样本，逐店复盘。

1. 先复盘已有调研报告的代表样本。
2. 验证“经营结果标签 -> 调研字段 -> 可能选址归因”是否说得通。
3. 对没有调研报告但经营结果非常典型的样本，再按同一字段结构补关键字段。
4. 把验证有效的字段升级为新点位调研必填项和候选点位判断规则。

## 生成文件

- 代表样本清单：`data/staging/site_attribution_review_plan.csv`
- 生成脚本：`scripts/build_attribution_review_plan.py`

## 当前代表样本

本轮每类经营结果标签最多挑 3 个样本，共 31 个。

优先先看已有调研报告的样本：

- 正向样本-新客驱动：上海荟聚店。
- 反向样本-租金高且营收弱：武汉天地店、上海久光百货店。
- 成长样本-新客强租售比健康：成都银泰中心in99店。
- 观察样本-经营期不足：深圳湾万象城店。

前三个样本可先跑通第一轮正反样本复盘闭环；成都银泰中心in99店用于观察“新客强、租售比健康但营收仍在爬坡”的成长样本；深圳湾万象城店经营期不足，不作为正反样本定性。

## 第一轮复盘问题

每个样本只回答四个问题：

1. 经营结果是什么：营收、租金、租售比、新客、理疗师产值分别处于什么位置。
2. 可能归因是什么：是客流/新客、租金压力、商场定位、竞品、客质，还是运营承接。
3. 调研报告里有没有提前出现这些信号。
4. 如果未来遇到类似新点位，哪些字段必须补、哪些字段可以降权。
