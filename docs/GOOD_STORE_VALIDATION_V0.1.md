# 好店完整验证 v0.1

## 当前结论

Hanson 的 `operate_monthly_indicator_data` 可接续2026-04以后的新客、老客、订单客次、留存和返店频次。当前主链已将完整月接到2026-06，225个日报门店月均有完整的新老客分段。

历史重叠期公式验证：

- 新客数/老客数：`cust_num` 按 `is_old=0/1` 分组，与王磊稿对应。
- 留存率：`consume_back_num / last_consume_num`，230个门店月平均绝对误差0.31个百分点。
- 返店频次：`cust_order_num / cust_num`，平均绝对误差0.02。
- 二次到店率：当前最接近公式平均误差仍为2.18个百分点，暂不接入。

## 初步业务解释

- 中海环宇城是当前最强的独立正向候选：营收最高、波动最低、近期仍增长；返店频次只在样本中下，说明其优势可能更偏新客和规模，而不是最高复购。
- 梅赛德斯奔驰文化中心的营收不算最高，但租售比健康、客户结构和稳定性较均衡，近期轻微回落需要继续观察。
- 大宁新铺经营和客户承接稳定，但这是同商场换铺后的承接结果，不能作为全新商场/全新商圈选址成功的独立证据。

完整服务器式刷新后，啦啦宝都的飞书当前租金更新为67,471元/月（此前本地旧值37,032.9元），近12月租售比为22.41%，因此已退出经济性达标名单。这也证明租金必须每次从线上只读刷新，不能长期依赖本地快照。

## 待王凯确认的 v0.1 规则

建议把完整好店拆为三个 Gate：

1. 经济性：月营收不低于28万、租售比不高于15%（已确认）。
2. 稳定性：至少12个完整经营月，营收波动CV不高于10%，近3月较此前不低于-10%。迁址/新铺6–11个月只标观察。
3. 客户健康：留存率或返店频次至少一项不低于同批样本中位数，避免把单纯靠短期获客冲高的门店定义为完整好店。

在以上规则确认前，代码只输出证据和分位，不自动将3店升级为“完整好店”。
