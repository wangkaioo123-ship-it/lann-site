# lann-site 选址分析 · 数据设计方案 v0.1

> 本文档定义 lann-site 项目的结果变量、点位主数据表结构与数据抽取优先级,作为 lann-site 仓库的初始设计文档。
> lann-site 为独立仓库,负责选址分析与 AI 判断;通过 Feishu 作为数据契约层与 lann-dashboard(展示层)对接。

---

## 一、"好选址"的操作化定义

选址好坏分三层判定,顺序不可颠倒:

| 层级 | 含义 | 判定方式 |
|---|---|---|
| 准入 Gate | 满足 LANN 基础开店要求 | 不满足直接出局,不进分析 |
| 约束 Constraint | 实际租售比 ≤ 标准值 | 问责红线,**达标即可,非越低越好** |
| 目标 Objective | 达标店中比业绩 | 营收 / 坪效 / 新客动能 / 测算达成率越高越好 |

一句话:**租售比是红线(达标),业绩是高下(排优)。** 具公司战略意义的点位单独标记,不进常规经济性判定。

---

## 二、贯穿全程的方法论原则

1. **真正要预测的是营收,不是租售比。** 租金在签约时已知,租售比的不确定性几乎全部来自营收。因子分析的预测对象是营收/业绩。
2. **约束 ≠ 目标。** "租售比越低越好"会把租金便宜的差位置误判为好店,与"以新客获取动能为核心"的风险模型冲突。租售比只作达标约束。
3. **必须有反例。** 只用已开业/存活门店存在 survivorship bias;需采集否决点位与关店案例作为负样本。
4. **强先验 + 小数据。** 样本量小(约 84 店),用已有领域知识(SABC、租售比、新客动能)作为待验证假设,而非纯数据驱动跑模型。
5. **forecast error 是金矿。** 立项测算 vs 实际经营的偏差,是校准选址判断最直接的反馈信号。
6. **技师产值用于剥离归因。** 同店技师人均产值/技师数,帮助区分"营收高是选址带来客流,还是技师能力/数量",缓解选址 vs 运营的归因混淆。

## 三、点位主数据表 schema(核心交付)

每个点位/门店 = 一行。字段按来源分组。**所有外部因子字段须带"数据来源 / 口径 / 采集时间"标注。**

### 3.1 标识与状态
点位ID、门店名、城市、城市线级、商场名、SABC评级、开业日期、当前状态(候选 / 否决 / 已开业 / 已关店)、是否战略性点位

### 3.2 地理 / 市场因子 — 来源:选址调研报告
人流量、动线评估、周边竞品数、互补业态密度、商圈消费力、人口结构、交通可达性(地铁距离 / 停车)
→ 每项配 `_数据来源`、`_采集工具`、`_采集时间` 三个附属列

### 3.3 商务条件 + 预算 + 测算 — 来源:立项信息表
月租金、租金单价、租期、免租期、递增率、转让费、押金、物业费、投资预算、**测算月营收**、测算毛利率、测算回本周期

### 3.4 实际经营结果 — 来源:门店经营数据(日颗粒,可聚合)
**实际月营收**、技师数、技师人均产值、新客数、坪效、毛利率、统计区间

### 3.5 派生结果变量(好选址判定)
实际租售比、租售比标准值、是否达标(布尔)、**营收达成率 = 实际营收 / 测算营收**、新客动能评分、好选址综合判定

### 3.6 反例字段 — 来源:否决记录 / 关店记录
否决理由、否决时调研数据、关店原因、存活月数

## 四、数据抽取优先级

### P0 — 先建"结果变量"这条线
- **门店实际经营数据**:已有、日颗粒、最干净。先把已开业店的实际营收 / 技师产值 / 新客聚合到月。
- **立项信息表**:结构化抽取,拿到商务条件 + 测算营收。
- → 这两条一接上,即可算出实际租售比、营收达成率,把已开业店的结果变量列填满。**先有靶子,后谈因子。**

### P1 — 补因子
- **选址调研报告抽取**:按 schema 抽地理 / 市场因子,逐字段标注口径。图片按第五节规则处理。

### P2 — 补反例 + 向前标准化
- 否决点位采集模板上线,新案例按统一口径录入。
- 关店原因回填到历史已关店门店。

## 五、图片与口径处理规则

- **数据型图片**(市调截图、热力图、房价表):关键数字人工转录或 OCR 后**人工核对**,转成字段;图片本身不进分析表。
- **佐证型图片**(门头 / 动线 / 实拍):规范命名后归档,主表用一列存路径,供溯源。
- **历史数据口径**:如实保留原始值 + 标注来源 / 工具 / 时间,**不强行抹平**;不可比者标注并分开处理。
- **向前标准化**:制定统一调研模板,新报告固定数据源与口径,保证未来数据可比。
- 原始报告归档至 `references/` 目录,只作溯源,不作日常输入。

---

## 六、最小闭环(第一步该做的)

用已开业门店,把已知的 3–4 个因子(SABC 评级、租售比、人流估计、技师产值)与实际营收 / 营收达成率做一次相关性 / 对比验证,确认哪些因子真有信号、哪些是错觉。跑通后再决定为哪些被验证的因子投入补外部数据。**不要一上来就搭大系统。**
