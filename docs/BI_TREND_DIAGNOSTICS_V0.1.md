## 可用指标

BI 不只有营业额，已读取到的经营字段包括：

- 收入：实际营收、现金流、开卡收入。
- 客流：新客数、老客数、订单客次。
- 客单：折扣前客单、折扣后客单、新客折扣前客单、新客折扣后客单、老客折扣前客单、老客折扣后客单。
- 转化：开卡人次、储值会员转化率。
- 留存：留存率、二次到店率、返店频次。
- 服务：点钟数、理疗师工作人天、理疗师日均服务客次、理疗师日均产值、理疗师生产率。
- 体验/私域：差评数、打赏次数、打赏金额、微信关注数。

当前选址归因 v0.2 应优先关注：

- 新客数量。
- 新客储值转化。
- 老客留存。
- 折扣前客单价。

理疗师产值、点钟、生产率等更多用于剥离运营承接因素。

## 2024Q4 后变化

全量季度口径：

- 2024Q3 实际营收：60,644,652.77；新客数：25,682；折扣后客单价：390.31；理疗师日均产值：1,395.99。
- 2024Q4 实际营收：58,324,816.13；新客数：24,886；折扣后客单价：383.39；理疗师日均产值：1,286.72。
- 2025Q1 实际营收：57,143,186.35；新客数：22,115；折扣后客单价：392.40；理疗师日均产值：1,424.95。

同店口径：选取 2024Q1 至 2025Q4 每个季度都有有效经营数据的 62 家门店。

- 2024Q3：单店月均营收约 304,308；单店月均新客约 126.0；折扣后客单价 391.2；理疗师日均产值 1,413.3。
- 2024Q4：单店月均营收约 287,026；单店月均新客约 118.2；折扣后客单价 384.5；理疗师日均产值 1,297.4。
- 2025Q1：单店月均营收约 277,300；单店月均新客约 103.8；折扣后客单价 393.6；理疗师日均产值 1,436.5。
- 2025Q4：单店月均营收约 282,250；单店月均新客约 106.2；折扣后客单价 385.2；理疗师日均产值 1,366.1。

初步判断：

- 王凯观察到的“2024Q4 大部分门店出现明显业绩下滑并持续至今”在同店口径下成立。
- 下滑不应简单归因为单店选址问题，更像公司/行业/消费环境/运营承接共同影响的系统性压力。
- 后续做选址归因时，必须把 2024Q4 之后作为一个新的经营阶段，避免用不同阶段的数据直接比较门店优劣。

## 对后续分析的要求

1. 选址归因必须区分时间阶段，至少拆分 2023、2024H1、2024Q4 后。
2. 正反样本不能只看总营收，需要看新客数量、新客储值转化、老客留存、折扣前客单价和租售比。
3. 2024Q4 后的下滑属于系统性背景，不能把所有下滑都归因到门店位置。
4. 对成熟门店做同店比较，比全量门店总盘更适合判断经营趋势。
