# 门店身份问题处理建议 v0.1

本文档只提出本地数据治理建议，不直接修改飞书源表或正式门店映射。

| 问题 | 当前事实 | 建议 | 需要确认 |
|---|---|---|---|
| 宝乐汇迁址 | 宝杨宝龙旧点位与宝乐汇新点位跨商场约 500 米 | 旧点位截至 2026-02-19，新点位从 2026-02-20 起；2 月过渡月不拆分 | 已确认 |

| 复兴 SOHO 空 ID | BI 名称为“新天地店”；中间停业装修但没有换铺 | 完整历史归入同一物理点位 `L0003`；空 ID 装修记录不生成新样本 | 已确认 |

| 全空记录 | 只有 `record_id`，没有门店名称和业务字段 | 从分析抽取中过滤，并在飞书检查是否可归档 | 是否保留源记录由业务侧决定 |

## 推荐规则

- 经营门店不等于物理点位：搬迁后可以沿用 Hanson 门店，但选址归因必须新建物理点位。
- 合同记录不等于物理点位：续签或重复录入不能自动产生新选址样本。
- 飞书 `record_id` 永久作为合同/源记录追溯键；正式点位 ID 作为物理位置键。
- BI 月数据需要增加“有效起止日期”，才能把同一经营门店在搬迁前后的月份分配到不同点位。
