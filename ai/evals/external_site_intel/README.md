# external_site_intel eval 样本说明

本目录用于沉淀外部选址情报任务的评测样本。第一阶段只做样本设计，不做大规模抓取。

## 单个样本应包含

- 输入：候选项目名称、城市、地址/商场地点、人工提供的外部链接。
- 标准答案：外部机会、外部风险、数据来源、可信度。
- 必须命中的证据：例如竞品密度、商场动态、负面新闻、客群匹配信号。
- 不允许犯的错误：无来源下编造热点；把外部热度当成最终开店结论；保存大段平台原文。
- 评分标准：来源可追踪、摘要准确、机会风险分离、可信度标注合理。

## 第一批建议样本

- 西岸梦中心：验证外部话题、区域发展、周边竞品。
- 深圳湾万象城：验证高端商圈和客群匹配。
- 成都 in99：验证商场人气风险。
- 温州印象城：验证非一线城市商场热度与客群。
- 荟聚：验证大型新商场的客流和招商动态。
