# site_candidate_screen eval 样本说明

本目录用于沉淀候选点位初筛任务的评测样本。第一阶段目标是先形成 10 个王凯认可的标准样本。

## 单个样本应包含

- 输入材料：候选项目字段、调研报告事实、经营基准参考。
- 标准答案：王凯认可的初筛结论。
- 必须命中的证据：例如租售比、租金口径缺失、调研报告缺失、外部情报风险。
- 不允许犯的错误：例如把“6个月”当成营收金额、把万元/元口径混用、跨城市误匹配同名商场。
- 评分标准：结论、证据、缺口、下一步动作是否准确。

## 第一批建议样本

- 西岸梦中心：有调研稳定营收和月租金物业成本，可计算租售比。
- 深圳湾万象城：有调研报告和预期营收，但缺租金口径。
- 成都 in99：调研报告中的“6个月”不能当营收。
- 温州印象城：候选营收小于 1000，需按万元口径暂估并标记。
- 荟聚：名称匹配必须受城市约束，避免跨城市错配。
