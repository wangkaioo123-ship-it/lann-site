# work_item_orchestration eval 样本说明

本目录用于沉淀“事项编排”任务的评测样本。第一阶段优先级最高，目标是连续跑 3-5 天，验证 AI 是否能稳定识别执行事项、判断事项和可能推翻原方案的事项。

## 单个样本应包含

- 输入：当天飞书待办、会议结论、项目日志、工作OS候选、王凯补充事项。
- 标准答案：王凯认可的事项分组和优先级。
- 必须命中的关系：依赖、冲突、重复、组合机会。
- 不允许犯的错误：只按时间排序；把判断事项当执行事项；漏掉可能影响原方案的事项；自动派任务或写飞书。
- 评分标准：分类准确、关系识别准确、建议动作可执行、没有越权动作。

## 第一批建议样本

- 新点位初筛相关事项：候选项目资料缺口、调研报告链接、dashboard展示、工作OS判断沉淀。
- AI矩阵推进相关事项：site/dashboard/工作OS前置工作、事项编排任务本身。
- 选址外部情报相关事项：地图/新闻/点评样本、外部数据归口。
- 日常经营待办：会议、沟通、数据补齐和团队委派混合在一起的真实一天。
